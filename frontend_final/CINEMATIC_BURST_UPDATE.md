# 电影感爆散更新

- 球体主体仍使用原来的 2100 个万花筒粒子，球形结构、配色和旋转逻辑不变。
- 每个主体粒子增加 5 个仅在爆散时显现的 GPU 碎屑，总绘制粒子约 12600。
- 碎屑带有延迟、弧形偏移、长短不同的飞行距离与尾迹层次。
- 第一次快速挥动：主体球体向外爆散，同时碎屑层展开，并产生短促镜头震动和曝光冲击。
- 第二次快速挥动：主体粒子与碎屑沿原轨迹倒放聚合；碎屑回到球面时自动淡出，恢复同一颗球。
- 所有碎屑继续沿用释放/舒缓两套原始配色，不引入新的颜色风格。
- 无戒指测试继续使用键盘 B 或页面“挥动：爆散 / 聚合”按钮。

性能参数：

- 主体粒子：2100
- 爆散碎屑：10500
- 爆散总粒子：12600
- 单个 `THREE.Points` + `ShaderMaterial` draw call
