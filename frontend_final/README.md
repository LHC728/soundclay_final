# SoundClay 前端｜万花筒球体雕刻版

这是一个基于 **Vite + Three.js + Web Audio** 的全屏声音粒子作品页面。保留原项目 2100 个万花筒粒子与“释放 / 舒缓”两套配色，并把雕刻动作改为可累计、不可自动回弹的三维形变。

## 已完成的核心动作

### 1. 转腕：万花筒变成 3D 球体

- 第一次有效转腕会把原平面万花筒平滑包裹到球面；
- 使用同一批粒子，不替换粒子颜色、数量或万花筒镜像关系；
- 球体跟随戒指转腕整体旋转，主轮廓不会被拉成长条；
- 松手后保留当前角度与球体形态，不返回平面；
- 球面粒子保持轻微呼吸和切向流动。

### 2. 快速挥动：粒子永久爆散

- `burst` 事件触发带切线弧度的三维爆散轨迹；
- 每个粒子拥有固定的方向、弧线和飞行距离；
- 爆散结果只增不减，不会自动聚拢或回弹；
- 爆散后粒子仍在当前位置持续微动；
- 可多次挥动叠加，逐渐形成个性化作品。

### 3. 向前推出：压扁并形成凹陷

- `push` 事件压缩整体 Z 轴深度；
- 画面中心产生带万花筒不规则边缘的可视化凹陷；
- 中心粒子略向外排开，增强“材料被按下去”的感觉；
- 压扁和凹陷可多次累计，不会恢复。

### 4. 双击：凝固作品

- `freeze` 事件或页面双击会冻结当前粒子位置和动画时间；
- 音频停止，进入结果页；
- 分享时生成当前全屏作品截图；
- 只有“重新开始”会清除全部形变。

## Three.js 实现方式

项目继续使用适合大量自定义粒子的方案：

- `THREE.BufferGeometry`：保存初始万花筒、球面位置、爆散方向与弧线等属性；
- `THREE.Points`：一次绘制全部 2100 个粒子；
- `THREE.ShaderMaterial`：在 GPU 顶点着色器中完成球化、爆散、压扁和凹陷；
- `PerspectiveCamera`：根据屏幕短边自动计算球体尺寸，根据长边计算爆散距离；
- 全屏 Canvas：桌面、宽屏和移动端自动适配。

这种方式比直接创建一个普通 `SphereGeometry` 网格更适合本项目，因为它能让原万花筒粒子身份和两套颜色模式完整保留。

## 戒指 WebSocket 接口

默认地址：

```text
ws://127.0.0.1:8000/ws/ring
```

### 转腕 / IMU

```json
{
  "type": "imu",
  "timestamp": 1720000000000,
  "payload": {
    "sessionId": "SC-DEMO-001",
    "sequence": 100,
    "twist": 0.72,
    "accelMag": 0.45,
    "pitch": 0.1,
    "yaw": 0.2,
    "roll": -0.1
  }
}
```

- `twist`：`-1 ~ 1`，控制整体旋转方向与速度；
- `accelMag`：`0 ~ 1`，控制声音能量；
- `pitch / yaw / roll`：可选，预留为弧度制完整姿态接口。

### 快速挥动

```json
{
  "type": "burst",
  "timestamp": 1720000000100,
  "payload": {
    "sessionId": "SC-DEMO-001",
    "sequence": 101,
    "strength": 0.9
  }
}
```

### 向前推出

```json
{
  "type": "push",
  "timestamp": 1720000000150,
  "payload": {
    "sessionId": "SC-DEMO-001",
    "sequence": 102,
    "strength": 0.85
  }
}
```

### 双击凝固

```json
{
  "type": "freeze",
  "timestamp": 1720000000200,
  "payload": {
    "sessionId": "SC-DEMO-001",
    "sequence": 103,
    "source": "key_double_press",
    "active": true
  }
}
```

离散事件使用 `sessionId + type + sequence/timestamp` 去重，避免一次动作被重复执行。

## 无戒指模拟

进入塑形页后可以直接测试：

- 鼠标左右拖动：转腕成球并旋转；
- 鼠标上下拖动：改变球体俯仰与声音力度；
- 快速甩动鼠标：爆散；
- 缓慢向上推动鼠标：压扁并形成凹陷；
- 页面双击：凝固作品；
- `← / A`、`→ / D`：持续转腕；
- `B`：爆散；
- `P`：压凹；
- `F`：凝固；
- `Space`：播放或暂停；
- 页面底部还保留“转腕成球 / 快速挥动 / 向前推出”测试按钮，戒指连接后自动隐藏。

## 本地运行

不要复制其他系统生成的 `node_modules`。解压后在项目目录重新安装：

```bash
npm install
npm run dev -- --host 0.0.0.0
```

浏览器打开终端显示的地址，通常是：

```text
http://localhost:5173/
```

麦克风功能需要 `localhost` 或 HTTPS。

## 构建

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

## 环境变量

复制 `.env.example` 为 `.env.local`：

```env
VITE_API_BASE=http://127.0.0.1:8000
VITE_WS_URL=ws://127.0.0.1:8000/ws/ring
```


## 快速挥动双态逻辑

- 第一次快速挥动：粒子沿固定的三维弧形轨迹爆散。
- 第二次快速挥动：同一批粒子沿原轨迹反向聚合，恢复爆散前的形态。
- 不会自动回弹；只有新的快速挥动事件才会切换爆散/聚合。
- 键盘 `B` 与页面“挥动：爆散 / 聚合”按钮使用相同逻辑。
