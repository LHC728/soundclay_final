# SoundClay 最终交互版 v4

## 最终动作映射

- 转腕：平面万花筒永久变成 3D 万花筒球，并随戒指整体旋转；粒子关系与球体轮廓不被拉长。
- 第一次快速挥动：从当前球体表面向四周爆散。
- 第二次快速挥动：同一批粒子沿原轨迹聚合，回到爆散前的球体、旋转角度和凹陷状态。
- 向前推：永久压扁球体、扩大轮廓，并在中心压出可视化凹陷。
- 向后拉：不是撤销或回弹，而是继续放大作品，并把凹陷边缘向镜头方向拉起。
- 双击：凝固当前作品，用于生成最终截图。

## 电影感爆散

- 主体粒子：约 2100 个，始终构成原万花筒与 3D 球体。
- 爆散碎屑：每个主体粒子附带 7 个延迟碎屑。
- 爆散总粒子：约 16800 个。
- 所有碎屑沿用主体粒子的圆形点精灵与原有两套配色。
- 通过延迟、弧形方向、尾迹副本、亮度冲击和短促镜头震动形成电影感。

## 无戒指测试

- 鼠标横向拖动：转腕成球并旋转。
- 快速甩动：爆散 / 聚合切换。
- 缓慢向上拖动：前推压凹。
- 缓慢向下拖动：后拉放大。
- 双击画面：凝固。
- B：爆散 / 聚合。
- P：前推。
- L：后拉。
- F：凝固。
- A / D 或左右方向键：旋转。

## 保留的戒指接口

WebSocket：

- `twist`：`payload.value`，范围 `-1 ~ 1`。
- `imu`：支持 `twist / accelMag / pitch / yaw / roll`。
- `burst`：`payload.strength`。
- `push`：默认前推；可传 `payload.direction: "backward"` 或负数 `payload.depth/value` 触发后拉。
- `pull`：后拉事件，支持 `strength / depth / value`。
- `freeze`：双击凝固事件。

浏览器自定义事件 `soundclay:gesture` 同样支持 `rotate / burst / push / pull / depth / tap / freeze`。
